# OmniVAC
OmniVAC - The Dockerized multi-phase drive tester with visual feedback, notifications, and Asimov-inspired interface

## Features
- Single-drive testing with zero-fill, write, verify, and SMART checks
- Block visualizations with granular stages
- Start / Pause / Resume controls
- Progress bars, countdown timers, and SMART Trend tracking
- Desktop, email, webhook notifications
- Persistent state and append-only historical logs using drive S/N
- Multi-container peer awareness
- Adaptive resource management with warning banners
- Asimove Easter Eggs
